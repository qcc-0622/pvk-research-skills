# PVK Polishing — 钙钛矿论文润色

> 先读 `context.md` 获取领域背景，再读 `journal_writing_rules.md` 获取期刊精确规范（基于10篇真实论文提取）。润色时 Priority 4（必删列表）和 Priority 2 规则优先。

## 润色原则

- 保留作者原意，不改变科学内容
- 美式英文（Wiley 规范）
- 单位上标：mA cm⁻²、cm⁻³、W m⁻²
- 句子 ≤30 词，避免从句套从句
- 动词精准：demonstrate > show；indicate > mean

## 检查清单

**语言层面：**
- [ ] 美式拼写（color / analyze / center）
- [ ] 单位格式（mA cm⁻² 非 mA/cm²）
- [ ] 数字与单位间有空格（1.2 eV）
- [ ] 时态一致（Results 用过去时，普遍规律用现在时）
- [ ] 冠词（the perovskite film / a champion device）

**专业层面：**
- [ ] 术语一致（同一概念全文统一）
- [ ] 表征缩写首次出现给全称
- [ ] 图表引用格式：Figure 1a（非 Fig.1a 或 fig 1a）
- [ ] 数据引用有括号：(PCE = 23.5%, Table 1)

**Wiley 特有：**
- [ ] Results and Discussion 段落：先结论后数据
- [ ] 图注完整（每个子图单独说明）
- [ ] 避免"novel"、"first time"（除非有文献支撑）
- [ ] 避免"we believe"、"we think"（改用 this suggests）

## 输出格式

1. **润色后原文**（标注修改处）
2. **修改说明**（每处改动的原因）
3. **仍需作者确认的数据/细节**
