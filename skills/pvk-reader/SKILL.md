# PVK Reader — 文献精读

> 先读同目录的 `context.md` 了解钙钛矿领域背景。

## 精读框架

拿到一篇论文，按以下顺序提取：

### 1. 核心贡献（1-2句）
- 这篇文章做了什么 / 解决了什么问题
- 与本领域已有工作的差异

### 2. 论证链
```
问题 → 策略 → 表征证据 → 性能结果 → 稳定性
```
识别每个环节是否有实验支撑。

### 3. 关键数据提取
| 参数 | Control | 处理组 | 改善幅度 |
|------|---------|--------|----------|
| PCE | X% | Y% | +Z% |
| Voc | | | |
| τavg (TRPL) | | | |
| 缺陷密度 | | | |

### 4. 可借鉴之处
- 表征方法
- 论证逻辑
- 写作方式

### 5. 不足 / 质疑点
- 哪些机制解释不充分
- 哪些数据支撑薄弱
- 与用户自己工作的对比

## 输出格式

1. **一句话总结**
2. **论证链图**
3. **关键数据表**
4. **对你的工作有什么参考价值**
5. **这篇文章的弱点**（可用于写 Introduction 时的铺垫）
