# PVK Response — 审稿回复

> 先读 `context.md` 获取领域背景知识。

## Wiley 回复格式

```
Dear Editor and Reviewers,

We thank the reviewers for their constructive comments...

[逐条回复]

Reviewer 1, Comment 1:
[原文引用审稿意见]

Response:
[你的回复]
[如有修改，说明在稿件哪里：We have revised... in the revised manuscript (Page X, Line Y).]

---
```

## 钙钛矿常见审稿问题 & 应对

| 常见质疑 | 应对策略 |
|----------|----------|
| 效率不够高 | 强调机制创新，横向比较相同策略的提升幅度，引用近期同类工作PCE范围 |
| 缺乏稳定性数据 | 补充具体测试条件（ISOS协议）和保留率，说明加速老化等效性 |
| 机制不清楚 | 补充DFT计算 / 额外光谱实验 / 引用已有文献类比机制 |
| 与已有工作重复 | 列出本工作的独特之处：分子设计/功能/应用场景差异 |
| 重现性问题 | 提供统计数据（≥20个器件的PCE分布图），补充误差棒 |
| 缺乏对照实验 | 补做或解释对照实验不必要的原因 |
| XPS 峰位移解释不够 | 结合DFT计算或NMR进一步证明相互作用 |
| TRPL 拟合参数不合理 | 说明拟合方法，提供拟合质量参数（χ²） |
| 没有EQE数据 | 补测，或说明Jsc已通过JV曲线积分验证 |
| 缺少大面积器件 | 补做或说明这是机制研究文章，大面积是future work |
| 铅毒性问题 | 引用封装技术 / 钙钛矿回收研究 / 与其他PV技术类比 |
| 与NREL认证效率差距大 | 说明实验室小面积器件与认证条件的差异，无需道歉 |

## 回复原则

- 感谢但不卑微
- 先认可审稿人的关切，再解释
- 每条回复末尾说明稿件修改位置
- 不能做的实验：诚实说明原因，提供替代证据

## 输出格式

每条审稿意见：
1. **引用原意见**
2. **Response**：感谢 + 解释/补充数据 + 稿件修改说明
3. **需要作者补充的内容**（如需要补实验）
